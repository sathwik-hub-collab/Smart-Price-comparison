# Smart-Price-comparision
Price Hunt is a Java-based e-commerce price comparison application that helps users compare product prices, discounts, delivery charges, seller ratings, and availability from multiple sellers in one place. Built using Java, Spring Boot, HTML, CSS, and JavaScript.

🛒 Price Hunt – E-Commerce Price Comparison Application

Find Better Deals. Compare Smarter. Save More!

Price Hunt is an e-commerce price comparison application developed as part of our Advanced Java Programming course at SRM University–AP.

The application helps users compare products from different sellers in one place. Users can check product prices, discounts, delivery charges, seller ratings, and product availability to find suitable deals.

✨ Key Features

- 🔍 Product Search – Search for products easily.
- 💰 Price Comparison – Compare prices from different sellers.
- 🏷️ Discounts – Check available product discounts.
- 🚚 Delivery Details – View delivery charges.
- ⭐ Seller Ratings – Check seller ratings.
- 📦 Product Availability – View product availability.
- 🗂️ Category Browsing – Explore products by category.
- ⚙️ Sorting & Filtering – Find products based on preferences.
- ❤️ Favourites – Save favourite products for later.

💻 Technologies Used

- Java
- Spring Boot
- HTML5
- CSS3
- JavaScript
- MySQL
